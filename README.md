# Alvin Kiprotich – Portfolio

Personal portfolio site: software developer in Nairobi, founder of RideRescue Autolink and lead developer of Grassva.

Live site: https://alvinkiprotich-dev.github.io

## About the code
- A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step).
- Font: Archivo via Google Fonts, with a system fallback.
- Profile photo and certificate images are embedded in the page, so nothing else needs to be hosted.
- Features: animated RideRescue request demo, scroll-lit experience timeline, filterable certificate gallery with a viewer, light/dark mode, and reduced-motion support.

## Run locally
Open `index.html` in any browser.

## Deploy with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.
